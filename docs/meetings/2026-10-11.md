**안건 5 : 추후 개발 일정 리마인드 및 코드 리뷰 방법 공부**

</aside>

- 조회 · 등록 기능은 중간고사 종료 후 약 일주일 뒤 완성을 목표로 함.

- 이제 많이 해야하는 PR 리뷰를 위해, 화면을 공유하여 
- File changed 탭에서 코드에 리뷰를 다는 방법, Approve 하는 방법 등을 다 같이 해보면서 익혔음.


<aside>

**안건 6 : AI 생성 코드 및 스타일 작성에 대한 의논**

</aside>

- 협업과 코드 학습을 위해 자신이 커밋한 기능 코드는 직접 설명할 수 있어야 함을 리마인드
- AI 생성 코드를 그대로 커밋하지 않고, 이해한 내용만 간략하게 정리하여 사용하기로 함.
- 디자인보다 기능 구현에 집중하고 불필요한 파일·스타일·중복 코드를 추가하지 않기로 함.
- 기존 스타일을 우선 재사용하고, 새 스타일의 필요성을 주석으로 명시하며 공통 변경의 영향을 확인하기로 함.

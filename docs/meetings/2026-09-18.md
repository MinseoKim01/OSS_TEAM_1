#### 확정: 교내 분실물 관리 프로그램

- 해결하려는 문제: 교내 분실물 정보가 여러 게시판이나 단톡방에 흩어지는 문제를 해결합니다.
- 본인 사례: 1학기에 누리관 향파관 사이에서 에어팟을 떨어트린 적이 있는데, 다행히 컴공학생이 주워 컴퓨터공학과 학과 사무실에 가져다주었고, 단톡방을 확인해서 찾을 수 있었다. 다른 과 학생이 주워 다른과 학과 사무실에 가져다 주었고 해당 과의 단톡방에만 공지가 되었다면 찾을 수 없었을 것이다. 이로 인한 분실물도 꽤 될 것이라 생각한다.
- 핵심 아이디어: 교내 분실물을 습득한 사람이 해당 사이트에 입력하도록 만들자!
- 기능 구분:
    - 공통 기능: 메인 페이지 구현
    - feature/view - 분실물 목록 및 상세 조회
    - feature/register
        - 분실 관련 학과 단톡 내용 등록 - 안내 날짜/시간/물건이름/특징/단톡방이름/비밀번호4
        - 현실에서 습득했을 때 등록 - 습득 날짜/시간/장소/물건이름/특징/둔 장소/비밀번호4
    - feature/search
        - 날짜, 물건명, 특징, 단톡방 이름, 장소 등으로 검색
    - feature/delete
        - 등록된 분실물 게시글 삭제 - 비밀번호 입력해서 일치하면 삭제 가능
